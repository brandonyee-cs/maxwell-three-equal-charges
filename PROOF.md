`main : H1 → H2 → type_of% @...three_equal_magnitudes`. Both hypotheses are self-contained real 2-D
statements. Charges sit at (0,0), (1,0), (u,w) with w ≠ 0. Write δ_j = p − b_j and R_j = |δ_j|.
* The planar equilibria are the points p ≠ b_j with Σ q_j δ_j / R_j^3 = 0, in both coordinates.
* The 2-D Hessian of V = Σ q_j/R_j is [[Σ q(2δx²−δy²)/R^5, Σ 3q δxδy/R^5], [Σ 3q δxδy/R^5, Σ q(2δy²−δx²)/R^5]].
* **H1** (charges all equal): if the 2-D Hessian determinant is non-zero at every planar equilibrium,
  there are at most 4 planar equilibria.
* **H2**: the same for |q_i| all equal with mixed signs.

Both follow from Tsai's theorem. Non-singular 2-D Hessian ⇒ isolated equilibrium, and the planar
equilibria are exactly the 3-D equilibria (Lemma P).

Transfer proved in Lean (`planar_transfer`), via:
* `exists_frame`: Gram–Schmidt gives f1 = a1 − a0 and f2 ⊥ f1 with ‖f2‖ = ‖f1‖, so that
  a2 = a0 + u f1 + w f2 and w ≠ 0 (w ≠ 0 by affine independence).
* `frame_norm`, `frame_inner`, `frame_eq_zero`: the map ψ(s,t) = a0 + s f1 + t f2 is a similarity.
* `coords_field`: field(ψ p) = L^{-3}((2-D field)_x f1 + (2-D field)_y f2), with L = ‖f1‖.
* `field_hasFDerivAt'`, `not_nondegenerate'`: the exact 3-D Hessian, D(field)v = Σ (q/r^3) v − 3q⟨d,v⟩/r^5 d.
  A nonzero v killed by it makes the 3-D Hessian degenerate.
* `coords_kernel`: for v = v1 f1 + v2 f2, the 3-D expression equals −L^{-3}(H₂D v)₁ f1 − L^{-3}(H₂D v)₂ f2.
  Since R² = δx² + δy², a 2-D kernel vector (`kernel2`, which exists when det = 0) gives a 3-D one.
* `eq_coords`: every 3-D equilibrium is ψ(p) for some p. The equilibria lie inside ψ''(2-D set), and
  `Set.encard_image_le` gives encard ≤ encard(2-D set).

## The named hypothesis of lean/MaxwellThreeEqual/ThreeEqual.lean (`PlanarTsai`)

```lean
def PlanarTsai : Prop :=
  ∀ (q : Fin 3 → ℝ) (a : Fin 3 → E), AffineIndependent ℝ a → (∀ j, q j ≠ 0) →
    (∀ i j, |q i| = |q j|) →
    (∀ x ∈ equilibria q a, HasNondegenerateHessianAt (potential q a) x) →
    {x ∈ equilibria q a | x ∈ affineSpan ℝ (Set.range a)}.encard ≤ 4
```

In words: three charges of equal magnitude at the vertices of a non-degenerate triangle, all of whose
equilibria are non-degenerate, have at most 4 equilibria **in the plane of the triangle**. This is
the planar, non-collinear case of Tsai's theorem (Physica D 309 (2015), 86–98). Tsai bounds the
number of *isolated* equilibria by 4. Non-degenerate equilibria are isolated, so H1 follows from
Tsai's theorem. It remains unproved in Lean.

## What is proved in Lean (all sorry-free; axioms checked: propext, Classical.choice, Quot.sound)
1. `potential_hasGradient`, `mem_equilibria_iff`: away from the charges,
   ∇V(x) = −Σ q_j (x−a_j)/|x−a_j|^3, so equilibria = zeros of the field.
2. **Lemma D** `not_nondegenerate`: suppose x is an equilibrium, some u ≠ 0 is orthogonal to every
   x − a_j, and Σ q_j/|x−a_j|^3 = 0. Then the Hessian of V at x is degenerate. This is done by an
   explicit derivative of the field: D(field)(x)u = (Σ q_j/r_j^3) u.
3. **Lemma L** `oneD_count`: for any reals r_j and equal-magnitude nonzero q_j, the set
   {s ∉ {r_j} : Σ q_j (s−r_j)/|s−r_j|^3 = 0} has encard ≤ 4. The proof gives at most one root per
   cell between consecutive r_j. Two roots s < s' in one cell would satisfy (up to sign)
   1/α² = 1/β² + 1/γ² at both points, while the ratios α²/β² and α²/γ² strictly increase (or both
   strictly decrease) across the cell (`ratio_up`, `key`, `cell`).
4. `collinear_case`: collinear charges, equal magnitudes, `hnd` ⇒ ≤ 4 equilibria. An off-line
   equilibrium forces Σ q_j/r_j^3 = 0, so Lemma D applies with u ⊥ span{x − p₀, v}. That u exists
   because dim span ≤ 2 < 3 (`exists_orth`), which contradicts `hnd`. On-line equilibria inject into
   the 1D root set of Lemma L.
5. **Lemma P** `equilibria_subset_affineSpan`: for affinely independent positions every equilibrium
   lies in the plane of the charges. If w_j = q_j/r_j^3 and Σ w_j ≠ 0, then x is an affine combination
   of the a_j. If Σ w_j = 0, affine independence forces w = 0, which is impossible.
6. The assembly then splits into two cases. If a is affinely independent, use H1 together with
   Lemma P. Otherwise a is collinear and step 4 applies.

## Why H1 is not proved
Counting the planar equilibria of a non-degenerate triangle is the core of Tsai's 13-page argument.
The index-theory identity #saddles − #extrema = 2 (Poincaré–Hopf) is not available in Mathlib. An
algebraic elimination does not obviously reach degree 4: GNS get 12 for positive charges, and
GNNS (arXiv:2607.28785) get 6.


## Appendix: the upstream statement, faithfulness, and literature (from the project notes)

Upstream file: `FormalConjectures/Arxiv/2607.27197/MaxwellConjecture.lean` in formal-conjectures at commit
`9097e2f9` (module `FormalConjectures.Arxiv.«2607.27197».MaxwellConjecture`).

### Definitions in plain words
* `potential q a x = Σ_j q_j / dist x (a_j)` on `EuclideanSpace ℝ (Fin 3)` (junk value at the charges,
  which never matters because `equilibria` excludes the charges).
* `equilibria q a = {x | x ∉ range a ∧ ∇ (potential q a) x = 0}`. Away from the charges V is smooth,
  so this is exactly `{x ∉ range a | Σ_j q_j (x - a_j)/|x - a_j|^3 = 0}` (field balance).
* `HasNondegenerateHessianAt V x : ∀ v ≠ 0, ∃ w, D²V(x)[v,w] ≠ 0` (Hessian non-singular).

### Targets
1. **Main (open)** `maxwell_conjecture.variants.three_charges`: for every q : Fin 3 → ℝ with all q_j ≠ 0,
   a injective, and *all* equilibria non-degenerate, `(equilibria q a).encard ≤ 4`.
2. **Side (known)** `maxwell_conjecture.variants.three_equal_magnitudes`: the same with the extra hypothesis
   `∀ i j, |q i| = |q j|`. Reference: Y.-L. Tsai, *Maxwell's conjecture on three point charges with equal
   magnitudes*, Physica D 309 (2015) 86–98, doi:10.1016/j.physd.2015.07.007. Per the abstract (ADS /
   ScienceDirect summary): for charge ratios 1:1:1 and 1:−1:−1 the number of **isolated** equilibria is
   0, 2, 3 or 4, for every configuration in R^3.

### Faithfulness
* Signs: "equal magnitudes" in Lean allows mixed signs (`|q i| = |q j|`), matching Tsai (1:1:1 and 1:−1:−1;
  global sign flips do not change the equilibria).
* Tsai counts *isolated* equilibria; Lean assumes all equilibria non-degenerate (⇒ isolated) and counts
  all of them. Non-isolated equilibria occur only for collinear charges (circles around the axis); these are
  degenerate (proved below, Lemma D), so the Lean hypothesis `hnd` simply excludes such configurations.
  Lean statement is therefore implied by Tsai's theorem. No mistranslation found.
* `n = 3`, `(n-1)^2 = 4` is hard-coded as `4`. Fine.
* `three_charges` with no sign / magnitude restriction: GNS (2007) give 12 for three positive charges
  (abstract of arXiv:2607.28785 quotes "at most 12 nondegenerate equilibria"); Gabrielov–D. Novikov–
  T. Novikov–Shapiro, arXiv:2607.28785 (July 2026), improve this to **6** for three *positive* charges.
  For mixed signs nothing sharper is known to us. Arathoon–Ball–Kvalheim (arXiv:2607.27197): "it is not
  known even for n = 3 if 4 is the maximum number, except in the case of equal charges [Tsai]".

### Elementary structure (all charges, any signs) — used in the Lean work
Write w_j = q_j / r_j^3, r_j = |x − a_j|. Equilibrium ⇔ Σ w_j (x − a_j) = 0.
* **Lemma P (planarity).** If the a_j are affinely independent, every equilibrium lies in their plane.
  Proof: decompose x = p + h n (n normal). Normal component: h Σ w_j = 0. If h ≠ 0 then Σ w_j = 0 and then
  Σ w_j a_j = 0, so w = 0 by affine independence, contradiction (q_j ≠ 0).
* **Lemma D (collinear, off-axis).** If the a_j lie on a line L and x ∉ L is an equilibrium, then Σ w_j = 0,
  and for v ⊥ span(L-direction, x − a_1), D²V(x)[v,w] = −(Σ w_j)⟨v,w⟩ = 0 ∀ w, so x is degenerate.
  Hence under `hnd` all equilibria of collinear charges lie on L.
* **Lemma L (on the line, equal magnitudes).** For s_1<s_2<s_3 and ε_j = ±1, the scalar equation
  Σ ε_j (t − s_j)/|t − s_j|^3 = 0 has at most one root in each of the 4 open cells, so ≤ 4 (in fact ≤ 2).
  Per-cell argument: in a cell put c_j = ε_j sgn(t − s_j); the equation is Σ c_j/u_j^2 = 0, u_j = |t − s_j|.
  All c equal ⇒ no root. Otherwise (up to sign) 1/u_i^2 = 1/u_j^2 + 1/u_k^2, and
  ρ_j = (u_i/u_j)^2 has derivative sign sgn((t−s_i)(s_i−s_j)(t−s_j)) constant on the cell; at a root
  u_i < u_j, u_k which forces both signs equal, so ρ_j + ρ_k is strictly monotone on the cell.
* Planar index count (Poincaré–Hopf, Σq ≠ 0): #saddles − #extrema of V|plane = 2, so a 5th equilibrium
  forces ≥ 2 local extrema of V|plane. For positive charges every equilibrium is in the open triangle
  (barycentric coordinates ∝ q_j/r_j^3 > 0) and V|plane has no local max (in-plane Laplacian Σ q_j/r_j^3 > 0).

### Numerical exploration (L1, floating point)
For the main target `three_charges` (no magnitude restriction) and for the equal-magnitude case, multistart
Newton searches in the plane (`scripts/search3.py`, `scripts/search_walk.py`, `scripts/equal_stats.py`)
found no configuration with more than 4 equilibria: 2 x 15000 random configurations with general charges
(`logs/search3_11.log`, `logs/search3_12.log`), a random walk of about 17000 steps inside the region with
4 equilibria (`logs/walk_1.log`), and 1200 random equal-magnitude configurations (`logs/equal_stats.log`).
These are heuristics, not exact computation; they found no counterexample and give no proof.
